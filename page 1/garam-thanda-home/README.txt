GARAM THANDA — HOME PAGE

Files:
- index.html: home page structure
- style.css: colours, layout, typography and responsive styling
- script.js: mobile navigation interaction
- food-illustration.svg: original local illustration used in the hero section

HOW TO RUN:
1. Keep all four files in the same folder.
2. Open index.html in a web browser (double-click it, or use Live Server in VS Code).

NOTES:
- The Our Menu and Our Story navigation links point to menu.html and about.html. Those pages are intentionally not included yet; they can be created as the next two pages of the website.
- The food prices and ratings are sample website content. Change them to your own menu details if required.
- Google Fonts are loaded online; system fallback fonts are included in the CSS.
- The page uses only HTML, CSS, and vanilla JavaScript. No framework is required.
