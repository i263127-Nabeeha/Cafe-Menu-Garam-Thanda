GARAM THANDA — CAFE & DHABA WEBSITE

Pages included:
- index.html: Home page
- menu.html: Detailed menu with search and category filters
- about.html: Our Story page with the imagined origin story of Garam Thanda

How to run:
1. Keep all files in this folder together.
2. Open index.html in a web browser.
3. Use the navigation links to move between Home, Our Menu and Our Story.

JavaScript interactions (Lab 11 practice):
- Home page: “A little chai surprise” button uses window.alert().
- Menu page: “Surprise me!” button uses window.alert().
- Our Story page: “A message from our kitchen” button uses window.alert().
- Menu page also includes working search and category filters.
- Mobile navigation opens and closes with the menu icon.

The origin story on about.html is fictional brand storytelling written for this website project, not a claim about a real cafe history. Menu items and prices are sample content in Pakistani rupees and can be edited.

Built with HTML, CSS and vanilla JavaScript. Google Fonts are loaded online; fallback fonts are included.
