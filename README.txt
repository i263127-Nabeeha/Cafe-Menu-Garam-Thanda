GARAM THANDA — CAFÉ & DHABA WEBSITE

PAGES
- index.html  : Home page
- menu.html   : Full menu with search and category filters
- about.html  : Our Story page
- order.html  : Order Online page with an interactive demo cart and a two-column favourites/rating table

SHARED FILES
- style.css            : Shared theme and responsive page styling
- script.js            : Mobile navigation, menu filters, Lab 11 alert buttons and demo cart
- food-illustration.svg: Homepage illustration

HOW TO RUN
1. Keep all files in this same folder.
2. Open index.html in a web browser.
3. Use the navigation links to move between the four pages.
4. On Order Online, view the favourites table, add items, adjust quantities, remove items and fill in the sample checkout form.

ORDER PAGE NOTE
The order page includes a simple two-column table of sample customer favourites and ratings, inspired by the original Lab 11 table. These ratings are illustrative only. The order page is a front-end demonstration only. The cart and sample checkout interaction work in the browser, but no order is transmitted to a restaurant, no database is connected and no payment is processed. To accept real orders, connect a backend or an ordering/payment service and configure it securely.

MENU NOTE
All menu items and prices are sample website content in Pakistani rupees (PKR). Edit them to match your project requirements.

TECHNOLOGY
HTML, CSS and vanilla JavaScript. Google Fonts are loaded online; fallback fonts are included in the CSS.
