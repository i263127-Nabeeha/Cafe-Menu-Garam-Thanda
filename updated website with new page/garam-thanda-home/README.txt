GARAM THANDA — HOME + DETAILED MENU

PROJECT FILES
- index.html: home page
- menu.html: detailed cafe/dhaba menu page
- style.css: shared colours, layout, typography and responsive styling
- script.js: shared mobile navigation, menu category filters and menu search
- food-illustration.svg: original local illustration used on the home page

HOW TO RUN
1. Extract this folder.
2. Keep all files together in the same folder.
3. Open index.html in a browser, or open the folder in VS Code and use Live Server.
4. Use the Our Menu link in the navigation or the home page menu button to open menu.html.
5. On the menu page, use the category buttons or search field to filter dishes.

DESIGN
The home and menu pages share the Garam Thanda palette: warm cream, maroon, red, mustard and olive; Playfair Display headings; DM Sans body text; and a warm Pakistani cafe/dhaba feel.

NOTES
- Menu names, descriptions and prices are sample content for this website project. Update them to match your final assignment requirements.
- The website uses HTML, CSS and vanilla JavaScript only. Google Fonts are loaded online; fallback fonts are included.
- The Our Story link currently returns to the welcome section on the home page. It can be redirected to about.html when the third page is created.
